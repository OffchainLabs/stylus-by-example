# Contract Calls in Stylus

The Stylus SDK provides Solidity-ABI-equivalent contract calls, letting you interact with other contracts without knowing their internals. Define Solidity-like interfaces with the `sol_interface!` macro and invoke them from Stylus (Rust) in a type-safe way.

For more on `sol_interface!` and how to use it in Rust Stylus contracts, see the **interface** page. You can also learn how to extract interfaces from Stylus contracts on the **interface extraction** [page](./interfaces).

### Example interfaces

```rust
sol_interface! {
    interface IService {
        function makePayment(address user) payable external returns (string);
        function getConstant() pure external returns (bytes32);
    }

    interface IMethods {
        function pureFoo() external pure;
        function viewFoo() external view;
        function writeFoo() external;
        function payableFoo() external payable;
    }
}
```

---

## Invoking Contracts Using the Interface

Solidity methods like `makePayment` are exposed in **snake\_case** in Rust. You also pass a **call context** that specifies gas/value and whether the call is mutating.

```rust
// Simple payable call via interface
pub fn simple_call(
    &mut self,
    account: IService,
    user: Address,
) -> Result<String, Vec<u8>> {
    let config = Call::new_mutating(self);                   // write/payable context
    Ok(account.make_payment(self.vm(), config, user)?)       // CamelCase -> snake_case
}
```

## Configuring Gas and Value for Contract Calls

Use the `Call` builder to set gas and the transferred Ether amount:

```rust
#[payable]
pub fn call_with_gas_value(
    &mut self,
    account: IService,
    user: Address,
) -> Result<String, Vec<u8>> {
    let config = Call::new_payable(self, self.vm().msg_value()) // forward msg.value
        .gas(self.vm().evm_gas_left() / 2);                     // use half of remaining gas
    Ok(account.make_payment(self.vm(), config, user)?)
}
```

* `Call::new()` → read-only context (pure/view)
* `Call::new_mutating(self)` → write context
* `Call::new_payable(self, value)` → payable context with a value

## Interface Calls: `pure`, `view`, `write`, `payable`

Stylus handles the right storage access mode based on the call context you build:

```rust
pub fn call_pure(&self, methods: IMethods) -> Result<(), Vec<u8>> {
    Ok(methods.pure_foo(self.vm(), Call::new())?)
}

pub fn call_view(&self, methods: IMethods) -> Result<(), Vec<u8>> {
    Ok(methods.view_foo(self.vm(), Call::new())?)
}

pub fn call_write(&mut self, methods: IMethods) -> Result<(), Vec<u8>> {
    // call a view first with a non-mutating context
    methods.view_foo(self.vm(), Call::new())?;
    // then call a write with a mutating context
    let config = Call::new_mutating(self);
    Ok(methods.write_foo(self.vm(), config)?)
}

#[payable]
pub fn call_payable(&mut self, methods: IMethods) -> Result<(), Vec<u8>> {
    // do a write
    let config = Call::new_mutating(self);
    methods.write_foo(self.vm(), config)?;
    // then payable with zero value (example)
    let config = Call::new_payable(self, U256::ZERO);
    Ok(methods.payable_foo(self.vm(), config)?)
}
```

## Generic Calls with `TopLevelStorage`

When writing libraries, you may not have `&self`. Build the call context from a generic `TopLevelStorage`:

```rust
pub fn make_generic_call<T: TopLevelStorage + core::borrow::Borrow<Self>>(
    storage: &mut T,      // could be &mut self or any TopLevelStorage
    account: IService,    // interface for the target contract
    user: Address,
) -> Result<String, Vec<u8>> {
    let vm = storage.borrow().vm();
    let msg_value = vm.msg_value();
    let gas = vm.evm_gas_left() / 2;

    let config = Call::new_payable(storage, msg_value).gas(gas); // build context from generic storage
    Ok(account.make_payment(storage.borrow().vm(), config, user)?)
}
```

## Low-Level Calls: `call` and `static_call`

Drop down to raw calldata when you need it:

```rust
// bytes-in/bytes-out state-changing call
pub fn execute_call(
    &mut self,
    contract: Address,
    calldata: Vec<u8>,
) -> Result<Vec<u8>, Vec<u8>> {
    let config = Call::new_mutating(self)
        .gas(self.vm().evm_gas_left() / 2);             // use half gas
    let return_data = call(self.vm(), config, contract, &calldata)?;
    Ok(return_data)
}

// bytes-in/bytes-out static (view) call
pub fn execute_static_call(
    &mut self,
    contract: Address,
    calldata: Vec<u8>,
) -> Result<Vec<u8>, Vec<u8>> {
    let return_data = static_call(self.vm(), Call::new(), contract, &calldata)?;
    Ok(return_data)
}
```

## Unsafe `RawCall`

Maximum control, minimal safety. Use cautiously.

```rust
pub fn raw_call_example(
    &mut self,
    contract: Address,
    calldata: Vec<u8>,
) -> Result<Vec<u8>, Vec<u8>> {
    unsafe {
        let data = RawCall::new_delegate(self.vm())
            .gas(2100)
            .limit_return_data(0, 32)
            .flush_storage_cache()
            .call(contract, &calldata)?;
        Ok(data)
    }
}
```

> Tip: for a plain “pass calldata through” helper you can also use a safe wrapper, but here we show the raw delegate pattern.
