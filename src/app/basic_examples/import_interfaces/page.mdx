# Import interfaces

Interfaces let your Stylus contract call **other contracts** (Solidity, Stylus/Rust, etc.) using their Solidity ABI. You declare them with `sol_interface!`, then invoke methods from Rust with a **VM handle** (`self.vm()`) and a **call context** (`Call`).

---

## Declaring interfaces

Use `sol_interface!` with **Solidity syntax** (keep CamelCase names; Stylus computes selectors from these exact names):

```rust
sol_interface! {
    interface IService {
        function makePayment(address user) payable external returns (string);
        function getConstant() pure external returns (bytes32);
    }

    interface ITree {
        // other interface methods
    }
}
```

This generates Rust types `IService` and `ITree` that you can construct from an address (e.g., `IService::new(addr)`) or accept as parameters.

> Note on naming: Solidity `makePayment` (CamelCase) becomes `make_payment` when called from Rust. The ABI **selector uses the Solidity name**; the Rust method is **snake\_case** for ergonomics.

---

## Calling via an interface instance (address → client)

Create an interface bound to a target address, build the right `Call` context, and pass `self.vm()`:

```rust
use stylus_sdk::{
    alloy_primitives::Address,
    call::Call,
    prelude::*,
};

sol_interface! {
    interface IService {
        function makePayment(address user) payable external returns (string);
    }
}

#[public]
impl MyContract {
    #[payable]
    pub fn pay_user(&mut self, service_addr: Address, user: Address) -> Result<String, Vec<u8>> {
        let service = IService::new(service_addr);
        let ctx = Call::new_payable(self, self.vm().msg_value()); // set value; add .gas(...) if needed
        Ok(service.make_payment(self.vm(), ctx, user)?)
    }
}
```

* **view/pure** → `Call::new()`
* **write** → `Call::new_mutating(self)`
* **payable** → `Call::new_payable(self, value)` (optionally `.gas(limit)`)

## Calling when the interface is passed in (no address creation)

If your function receives the interface value directly, just build the context and call:

```rust
use stylus_sdk::{call::Call, prelude::*};
use stylus_sdk::alloy_primitives::Address;

sol_interface! {
    interface IService {
        function makePayment(address user) payable external returns (string);
    }
}

#[public]
impl MyContract {
    #[payable]
    pub fn do_call(&mut self, account: IService, user: Address) -> Result<String, Vec<u8>> {
        let ctx = Call::new_payable(self, self.vm().msg_value());
        Ok(account.make_payment(self.vm(), ctx, user)?)
    }
}
```

## View vs write examples

For a dedicated “methods” interface, use a **non-mutating** context for `view`/`pure` and a **mutating** context for `write`:

```rust
use stylus_sdk::{call::Call, prelude::*};

sol_interface! {
    interface IMethods {
        function viewFoo() external view;
        function writeFoo() external;
    }
}

#[public]
impl Contract {
    pub fn call_view(&self, addr: Address) -> Result<(), Vec<u8>> {
        let ext = IMethods::new(addr);
        Ok(ext.view_foo(self.vm(), Call::new())?)
    }

    pub fn call_write(&mut self, addr: Address) -> Result<(), Vec<u8>> {
        let ext = IMethods::new(addr);
        let ctx = Call::new_mutating(self);
        Ok(ext.write_foo(self.vm(), ctx)?)
    }
}
```

## Gas & value configuration (quick reference)

* Add value: `Call::new_payable(self, value)`
* Limit gas: `.gas(limit)`
* Read-only: `Call::new()`
* State change: `Call::new_mutating(self)`

Example:

```rust
let ctx = Call::new_payable(self, self.vm().msg_value())
    .gas(self.vm().evm_gas_left() / 2);
```
